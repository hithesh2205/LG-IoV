1. System Architecture & The F Aggregation Formulation

In this architecture, vehicular edge nodes (ECUs) capture CAN bus streams, extract 46 sliding-window descriptors, train a local Chebyshev Kolmogorov-Arnold Network (ChebyKAN), and produce local parameter updates \(\Delta w_k = w_k^{(t+1)} - w^{(t)}\).

Each client encrypts its update under CKKS \(c_k = ext{Enc}_{pk}(\Delta w_k)\) and transmits \((c_k, n_k)\) to the Roadside Unit (RSU), where \(n_k\) is the local sample count.

The Global F Aggregation Formulation:

\[ F(\{c_k, n_k\}_{k=1}^K) = rac{1}{N} \sum_{k=1}^K n_k c_k, \quad ext{where } N = \sum_{k=1}^K n_k \]

Execution Steps Under CKKS Without Homomorphic Division

Homomorphic division \( rac{[A]}{[B]}\) is avoided entirely by computing the scalar inverse \( rac{1}{N}\) in plaintext and applying native single-depth scalar multiplication:

  1. Plaintext-Scalar Multiplication: Multiply each ciphertext by its public sample count: \(c_k' = n_k \odot c_k\).
  2. Homomorphic Addition: Sum the resulting ciphertexts: \(c_{ ext{sum}} = \sum_{k=1}^K c_k'\).
  3. Normalization: Scale by the inverse total sample count: \(c_F = \left( rac{1}{N} ight) \odot c_{ ext{sum}}\).
  4. Model Update: The authorized key holder decrypts \(c_F\) to yield \(\Delta w_{ ext{global}} = ext{Dec}_{sk}(c_F)\), updating the global model: \(w^{(t+1)} = w^{(t)} + \eta \Delta w_{ ext{global}}\).
