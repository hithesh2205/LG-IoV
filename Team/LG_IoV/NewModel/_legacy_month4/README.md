# Legacy Month-4 scripts — archived, do not run

These scripts were written in Month 4 and **reference APIs that no longer exist**.
They are kept for provenance only. Running them will fail.

| File | Why it is archived | Replacement |
|---|---|---|
| `benchmark_real_ckks.py` | Measures **addition and plaintext-scalar multiplication only**. FheFL also needs a ciphertext×ciphertext multiply for the squared distance (eq. 11), which dominates the cost — so this benchmark understates FheFL overhead. | `scripts/benchmark_ckks_profiles.py` |
| `run_simulations.py` | Calls `FederatedServer.aggregate_rounds(..., f=...)` and the `use_fhe` flag, both removed with the Multi-Krum filter. | `scripts/run_all_experiments.py` |
| `build_comparison.py` | Joins Month-4 result files whose schema has changed. | `scripts/run_all_experiments.py` writes `results/month5_summary.json` directly |
| `build_pptx_slides.py` | Appends slides quoting the Month-4 numbers, which are invalid (filename labels, leaky split, simulated encryption). | — |
| `run_all_comparisons.sh` / `.ps1` | Shell wrappers around the above. | `scripts/run_all_experiments.py` |
| `run_all_comparisons.out` | Captured output of an invalid run. | `run_logs/` |

## Why the results these produced are invalid

Every number generated by these scripts predates the Month-5 fixes:

- **Labels came from filenames**, so the model was learning which capture file it
  was looking at rather than whether an intrusion was present (defect D1).
- **Overlapping windows were split randomly**, putting near-duplicates on both
  sides of the train/test boundary (defect D2).
- **"Encryption" was numpy plus N(0, 1e-9) noise**, which is below float32 ULP —
  not encryption, and it made the FHE/no-FHE comparison uncontrolled (defect D3).

The outputs are preserved in
`5th Month Progress/Results/month4_legacy_INVALID/` and **must not be
re-reported**.
