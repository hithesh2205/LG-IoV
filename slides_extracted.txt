Architecture Workflow: Client Domain vs. Untrusted Server
---
Client Domain (Possesses Secret Key sk):
• [1] Local Plaintext Data: 46 CAN statistical features 
• Local Training: Computes update: Δwk = wk(t+1) − w(t) ∈ ℝ44,164
• ( Encrypts Locally ): Encrypts via public key pk: ck = Encpk(Δwk)
• [2] Secure Ciphertext: Transmits (ck, nk) over vehicular 5G / V2X
Untrusted Server Domain (No Secret Key: sk = ∅):
• Receives Ciphertext: Ingests { (ck, nk) } blindly without seeing weights
• Computes Function F: Evaluates weighted FedAvg directly over ciphertexts
• New Result Ciphertext: Broadcasts aggregated global ciphertext cF
---
Downstream Decryption:
• [4] Broadcasts cF (3.52 MB) -> [5] Vehicles decrypt locally via sk
• Updates model: w(t+1) = w(t) + 1.0 · Δwglobal

Architectural Comparison: Plaintext vs. Homomorphic Function F
---
Plaintext Federated Learning (Baseline)
• Weight Exposure: Vehicles transmit raw weight deltas Δwk unencrypted
• Model Inversion Vulnerability: Eavesdroppers/RSU reconstruct vehicle CAN telemetry
• Server Computation: Computes standard float division: (1/N) ∑ nk Δwk
• Trust Assumption: Requires complete trust in roadside servers and communication channels
• Security Level: Zero cryptographic privacy on model weights
---
Homomorphic Function F 
• Ciphertext Confidentiality: Vehicles transmit strictly encrypted ciphertexts ck
• Provable Privacy: Individual weights and CAN traffic are mathematically concealed
• Server Computation: Evaluates F blindly via slot-wise scalar multiplication & addition
• Zero-Trust Server: RSU holds zero secret keys (sk = ∅); cannot decrypt any update

Formal Mathematical Formulation of Function F
---
1. Mathematical Definition of Function F (Weighted Aggregation)
• Suppose there are K vehicles participating in federated round t.
• Vehicle Variables in Round t:
  - nk: Number of local training records processed on vehicle k
  - Δwk: Local model update vector: Δwk = wk(t+1) − w(t) ∈ ℝ44,164
  - ck = Encpk(Δwk): Encrypted update vector (11 CKKS ciphertext chunks)
The Weighted Aggregation Function:
   F( {ck, nk}k=1K ) = ( 1 / ∑k=1K nk ) · ∑k=1K nk ck
Core Computational Rule: Plaintext Scalar Division
• Multiplication and addition involving ck are performed directly on ciphertexts using CKKS.
• Division means multiplying by plaintext scalar 1 / ∑k=1K nk, NOT dividing by ciphertext!
• Bypasses expensive ciphertext division [c1 / c2] entirely.

Mathematical Proof of Correctness: Decryption Linearity
---
Proof of Equivalence by Linearity of CKKS Decryption
• Decryption of aggregated output ciphertext across slot chunk j:
   Decsk( cF,j ) = Decsk( ∑k=1K αk ⊙ ck,j )
• By linearity of CKKS decryption across canonical embeddings:
   = ∑k=1K αk · Decsk( ck,j )
• Substituting plaintext scalar fractions αk = nk / N and decrypted updates Δwk,j:
   = ∑k=1K ( nk / N ) · Δwk,j = ( ∑k=1K nk Δwk,j ) / ( ∑k=1K nk ) = Δwglobal, j
Experimental Bitwise Parity & Numerical Error Bound
• Exact Parity: Decsk(cF,j) = Δwglobal, j matches classical unencrypted FedAvg exactly.
• Measured Numerical Error Bound: εagg = || Decsk(cF) − Δwunencrypted ||∞ = 8.174 × 10-7.
• Zero Accuracy Loss: Confirmed 99.83% multi-class accuracy with exactly 0.0000% FHE gap.

ChebyKAN Weight Representation & Edge Formulation
---
How Weights are Represented in ChebyKAN
• Connection Curves: Standard MLPs use scalar multipliers (w · x). ChebyKAN replaces each connection with a learnable Chebyshev polynomial curve: φ(x) = wb · x + ∑k=04 ck · Tk(xnorm)
• 6 Learnable Parameters per Edge: 1 base linear weight (wb) captures baseline linear trends + 5 Chebyshev coefficients (c0, c1, c2, c3, c4) shape non-linear attack boundaries.
• Orthonormal Chebyshev Basis: Uses T0=1, T1=x, T2=2x2-1, T3=4x3-3x, T4=8x4-8x2+1 defined over normalized range [-1, 1].
Native Cryptographic Compatibility (Why ChebyKAN?)
• Eliminates Non-Polynomial ReLUs: Traditional DNNs rely on ReLU/Sigmoid activations, which cannot be computed under CKKS without expensive high-degree polynomial approximations.
• Natively Algebraic: ChebyKAN non-linearities are purely algebraic polynomial operations, perfectly matching CKKS homomorphic additions and scalar multiplications.
