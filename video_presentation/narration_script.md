## 5 · The mathematics — ChebyKAN weights as polynomials  ·  02:30 – 03:19

- `02:31` Now the maths. A normal network multiplies each input by one weight.
- `02:36` ChebyKAN replaces that weight with a learnable curve built from Chebyshev polynomials.
- `02:41` T0 is 1, T1 is x, and each next one is 2x times the previous, minus the one before.
- `02:50` Each edge computes φ(x): a base weight times x, plus five coefficients times T0 to T4 of tanh x. Six parameters per edge.
- `02:59` With 46 inputs, two hidden layers of 64, and 4 classes, that is 7,296 edges,
- `03:08` giving 44,164 parameters in total, broken down here.
- `03:14` Because it is all polynomials, it suits CKKS arithmetic.

## 5 · The mathematics — CKKS packing and the function F  ·  03:19 – 04:15

- `03:20` CKKS encrypts real numbers. With N = 8,192, one ciphertext holds 4,096 values in parallel slots.
- `03:31` Each weight is scaled by 2 to the 40, and 44,164 weights fill 11 ciphertexts, the last one zero-padded.
- `03:40` The server's function F multiplies each encrypted update by its sample count, adds them, and scales by one over the total.
- `03:47` Only plaintext scalars touch the ciphertexts, so the multiplicative depth is zero.
- `03:53` Decryption is linear, so decrypting the result gives exactly the weighted average of the plain updates.
- `03:59` For robustness, each update's squared distance to the global model costs one ciphertext multiplication, and becomes a trust weight.
- `04:07` Vehicles decrypt and re-encrypt fresh every round, so noise never builds up and no bootstrapping is needed.
